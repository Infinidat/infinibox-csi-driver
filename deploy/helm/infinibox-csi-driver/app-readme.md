
## Prerequisites

1. Create a namespace to install the driver named "infinidat-csi".
2. Install the chart with the name "infinidat-csi-driver". The value.yaml file used during installation can be found [here](https://github.com/Infinidat/infinibox-csi-driver/blob/develop/deploy/helm/infinibox-csi-driver/values.yaml)

The document [here](https://github.com/Infinidat/infinibox-csi-driver/tree/develop/deploy/helm/infinibox-csi-driver) contains instructions on the driver and installation in general.
