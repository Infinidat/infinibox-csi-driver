
## Prerequisites

1. install the COSI driver into the same namespace as the CSI driver (e.g. "infinidat-csi").
2. Install the chart with the name "infinidat-cosi-driver". The value.yaml file used during installation can be found [here](https://github.com/Infinidat/infinibox-csi-driver/blob/develop/deploy/helm/infinibox-cosi-driver/values.yaml)
